Dependency Injection

DI: границы фич

  • Фичевые сервисы — route-scoped, не root singleton

  • UI инжектит только facade, не HttpClient

Team Story15 / 20
Decisions

Ключевые решения

  • Facade pattern — UI не знает про HTTP/Firestore
  • Shared domain в core — Confess + Candles для нескольких фич
  • Signals over NgRx Store — signalStore только для UI prefs
  • Taiga UI — единый kit, accessibility, form integration
  • Repository rulesets — 1 approval + required CI на develop
